# 企鹅厨房前端

本目录包含企鹅厨房机器人工作台和饮食健康管理页面。

## 包含内容

- `index.html`：入口和控制页面。
- `app.js`：12 道菜谱、三种模式、每次三道推荐、食材筛选和换一组。
- `style.css`：桌面和竖屏自适应布局。
- `images/`：12 道菜的独立照片与 4 组原始食材照片，使用带内容指纹的 WebP 文件。
- `nutrition_ui/`：饮食档案、饮食记录、健康记录和食谱推荐。
- `PHOTO_SOURCES.md`：图片参考来源。

## 静态预览

在仓库根目录执行：

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory pet_meal/ui
```

访问 http://127.0.0.1:8080/ 。静态预览可以使用菜谱模式、食材筛选、换一组和菜谱详情。实时观测与机器人运行控制需要同源后端 `/api/` 接口，静态文件服务器不提供这些接口。

## 现有后端集成

Python 后端从 `pet_meal/ui/` 提供页面。工作台侧边栏的“饮食健康”打开 `/nutrition_ui/index.html`，饮食页面顶部的“机器人工作台”可返回首页。饮食健康页面使用浏览器本地演示数据，页面内创建的制作任务在本地模拟。
