# 企鹅厨房前端

本目录是企鹅厨房的独立前端副本，源自 `pet_meal/ui/`。

## 包含内容

- `index.html`：入口和控制页面。
- `app.js`：12 道菜谱、三种模式、每次三道推荐、食材筛选和换一组。
- `style.css`：桌面和竖屏自适应布局。
- `images/`：12 道菜的独立照片与 4 组原始食材照片，使用带内容指纹的 WebP 文件。
- `PHOTO_SOURCES.md`：图片参考来源。

## 静态预览

在仓库根目录执行：

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory frontend
```

访问 http://127.0.0.1:8080/ 。静态预览可以使用菜谱模式、食材筛选、换一组和菜谱详情。实时观测与机器人运行控制需要同源后端 `/api/` 接口，静态文件服务器不提供这些接口。

## 现有后端集成

现有 Python 后端从 `pet_meal/ui/` 提供页面。本目录为单独存放和交付的前端代码，不会自动改变后端的静态目录。若将此目录部署到其他服务，请将 `/api/` 转发至 Python 后端，并提供 `/images/` 静态资源。
