## 错误与修复依据

- 默认沙箱无法连接 GitHub；在本次下载授权范围内使用网络执行权限完成官方资源下载。
- GitHub REST API 返回 rate limit exceeded；改用 Git 协议读取提交并克隆，不依赖 API。
- Python urllib 下载返回 `CERTIFICATE_VERIFY_FAILED`；使用 Windows PowerShell 系统证书下载官方资产，并核验 SHA256，没有关闭 TLS 验证。
- 初次可编辑安装遇到旧 setuptools 的临时路径花括号解析错误；升级项目虚拟环境构建工具后，又遇到沙箱临时目录 `WinError 5`。在授权范围内完成本地安装，保留正常 `python -m` 入口。
- Git LFS 工作区检查在沙箱内遇到 `NtCreateDirectoryObject` 权限错误；以只读授权检查生成四个 clean checkout 的提交锁定清单。
